# IKEA RFM Customer Segmentation Analysis

## Project Overview

This project analyzes customer purchasing behavior using RFM (Recency, Frequency, and Monetary) analysis. The goal is to segment customers into meaningful groups and identify valuable customer segments for targeted business strategies.

## Tools Used

- SQL Server Management Studio (SSMS)
- Python (Pandas)
- Power BI

## Project Workflow

### Data Preparation

- Combined retail datasets
- Removed duplicates
- Handled missing values
- Cleaned transaction records

### RFM Analysis

- Recency: Days since last purchase
- Frequency: Number of purchases
- Monetary: Total amount spent

### Customer Segmentation

Customers were categorized into:

- Champions
- Loyal Customers
- New Customers
- Needs Attention
- At Risk
- Lost Customers

### Dashboard Features

- KPI Cards
- Customer Segment Analysis
- Country\-wise Performance Analysis
- Customer Value Insights
- Interactive Slicers and Bookmarks
- Segment and Country Navigation

## Key Insights

- Champions generated the highest customer value.
- Loyal customers represented a significant portion of revenue.
- Certain countries contributed more revenue than others.
- At\-risk customers provide opportunities for re\-engagement campaigns.
